# XTREME 2026 — CSE Symposium Website

## Department of Computer Science & Engineering

### Francis Xavier Engineering College

A modern, immersive, and fully responsive symposium website built for **XTREME 2026**.

---

## Features

- **Smooth Animations:** GSAP-powered scroll animations, staggering reveals, and an interactive 0–100% loading screen.
- **Live Countdown:** Real-time countdown to March 27, 2026.
- **Event Information:** 8 core events featuring full rules, venue details, and timings presented in interactive modals.
- **Robust Registration:** Multi-step registration flow supporting both Individual and Team formats.
- **Payment Flow:** Built-in GPay QR scanner and payment screenshot upload capabilities.
- **Instant Data Sync:** Direct integration with Google Sheets for tracking participant data efficiently.
- **Seamless Navigation:** React Router integration for smooth, app-like transitions without page reloads.
- **Fully Responsive:** Beautifully optimized for mobile, tablet, and desktop viewing.

---

## Tech Stack

- **Core Engine:** React.js, Vite
- **Animations:** GSAP (GreenSock Animation Platform)
- **Routing:** React Router v6
- **Database/Backend:** Google Apps Script / Google Sheets

---

## Installation & Setup

```bash
# 1. Clone the repository (if not already done)
# git clone <your-repo-url>

# 2. Navigate to the project directory
cd xtreme26

# 3. Install dependencies using pnpm
pnpm install

# 4. Start the development server
pnpm dev

# 5. Open your browser
# Navigate to http://localhost:5173
```
